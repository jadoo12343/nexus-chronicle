# 🔮 Nexus Chronicle 2.0 - Cinematic Visual RPG

A side-by-side **Cinematic Visual RPG & Interactive Narrative Story Engine** built with HTML5, CSS3, and modern Vanilla JavaScript. Features an animated 16:9 Cinema Viewport ("Picture Movie"), multi-act branching campaigns, turn-based tactical combat, cyber hacking matrices, procedural audio synthesis, and luxury glassmorphic aesthetics.

---

## ✨ Features

- 🎬 **Side-by-Side Cinema Theater ("Picture Movie")**: Real-time procedural parallax canvas renderer with Ken Burns camera panning, dynamic weather (neon rain, embers, data dust), and animated hero/enemy actor cards.
- 📖 **3 Multi-Act Campaigns**:
  - **Neon Overdrive 2099** (Cyberpunk Sci-Fi)
  - **Eldritch Eclipse** (Dark Fantasy)
  - **Cosmic Odyssey: Void Abyss** (Cosmic Sci-Fi Horror)
- ⚔️ **Tactical Turn-Based Combat**: Strike attacks, neural EMP hacks, holy spells, defensive shielding, and emergency stims.
- 💻 **Cyber Hacking Matrix**: Interactive memory node sequence puzzle with ICE security traces.
- 🎒 **Inventory & Equipment Stash**: Weapon, Armor, and Implant/Relic loadouts with live attribute bonuses (STR, AGI, INT, WIL, LCK).
- 🎵 **Adaptive Procedural Audio**: Multi-stem procedural Web Audio synthesizer generating dynamic ambient drones, combat driving beats, and action sound effects.

## 🚀 Quick Start

### Running Locally

1. Clone or download this repository.
2. Open [`index.html`](index.html) directly in any modern browser, **or** start the local PowerShell server:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 3000
```

3. Navigate to **`http://localhost:3000`** in your browser.
